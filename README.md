# Python Learning Record

I started teaching myself Python in June 2026, studying on weekends and holidays
alongside my full-time job. This repository contains the exercises I wrote along the way.

## Contents

- `01-basics`: variables, conditionals, loops, and other fundamentals
- `02-strings`: string processing (including the Caesar cipher)
- `03-data-structures`: sequences, dictionaries, sets
- `04-functions`: functions, closures, decorators, lambdas, recursion
- `05-files`: file I/O, pickle, zip
- `06-oop`: object-oriented programming (classes, inheritance, mixins, etc.), including small systems such as a supermarket and car rental

## Notes

- The number at the start of each file name is the date I wrote it (e.g. `20260613`).
- Commit dates are restored from the original file modification times.
- Reference solutions provided by the course instructor are not included.
